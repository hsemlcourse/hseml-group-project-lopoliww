## Описание задачи {#описание-задачи}

**Задача:** регрессия.

**Идея:** по публичным характеристикам онлайн-курса и его учебных элементов предсказывать спрос на курс. В качестве таргета используется `learners_count` — количество учеников на курсе. Это связано с трафиком в онлайн-образовании: чем выше спрос на курс, тем больше учеников приходит на страницу курса и записывается на него.

**Единица наблюдения:** учебный шаг курса Stepik (`course_step`). Одна строка датасета — это шаг урока, обогащённый признаками курса, секции, юнита и урока. Такой формат нужен, чтобы получить 10 000+ реальных строк без синтетического размножения данных.

**Источник данных:** публичный REST API Stepik (`https://stepik.org/api`). Используются открытые `GET`-эндпоинты: `courses`, `sections`, `units`, `lessons`, `steps`.

**Целевая метрика:** RMSE по `log1p(learners_count)`. Дополнительно считаются MAE/RMSE в исходной шкале учеников. Логарифмирование нужно из-за сильной асимметрии: у небольшого числа курсов очень много учеников.

## Запуск {#запуск}

``` bash
# 1. Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
# .venv\Scripts\activate    # Windows PowerShell

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Спарсить реальные данные Stepik на уровне шагов курса
python -m src.scraping --pages 600 --granularity steps --output data/raw/stepik_course_steps.jsonl

# 4. Проверить количество сырых строк
python -c "from pathlib import Path; p=Path('data/raw/stepik_course_steps.jsonl'); print(sum(1 for _ in p.open(encoding='utf-8')))"

# 5. Подготовить датасет для CP1
python -m src.preprocessing --input data/raw/stepik_course_steps.jsonl --output data/processed/stepik_course_steps_processed.csv

# 6. Обучить baseline и модели-эксперименты
python -m src.modeling --input data/processed/stepik_course_steps_processed.csv --output-dir models

# 7. Проверить пайплайн и стиль
pytest tests/test.py -q
ruff check src tests
```

Для PowerShell команды можно запускать в одну строку, как показано выше.

## Данные {#данные}

Итоговый датасет содержит:

```text
16289 строк
53 колонки
```

Разбиение:

| Split | Количество строк |
|-------|------------------:|
| train | 12942 |
| val | 1698 |
| test | 1649 |

Датасет удовлетворяет требованиям CP1: больше 10 000 строк и больше 10 колонок, включая таргет.

-   `data/raw/stepik_course_steps.jsonl` — сырые строки уровня учебного шага. Каждая строка содержит признаки курса, секции, юнита, урока и шага.
-   `data/processed/stepik_course_steps_processed.csv` — таблица после очистки, feature engineering и разметки `split`.

Основные группы признаков:

-   признаки курса: название, описание, язык, рейтинг, отзывы, число уроков/секций, сертификат, платность/цена при наличии;
-   признаки структуры: позиция секции, количество юнитов, позиция юнита, количество шагов в уроке;
-   признаки шага: тип шага, позиция в уроке, стоимость шага, наличие видео;
-   текстовые признаки: длина названия/описания/названия урока, количество слов;
-   таргет: `learners_count`, также добавлен `target_log_learners_count`.

Split делается группами по `course_id`: все шаги одного курса попадают только в один из `train`/`val`/`test`. Это нужно, потому что у шагов одного курса одинаковый таргет, и обычный row-wise split дал бы утечку.
